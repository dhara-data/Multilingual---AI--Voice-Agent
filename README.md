Multilingual AI Voice Assistant

📌 Project Overview

The Multilingual AI Voice Assistant is an AI-powered application that allows users to ask questions through text or voice. It provides responses in multiple languages and can answer questions about education, programming, Artificial Intelligence, technology, business, shopping, and general knowledge.

The application uses Streamlit for its user interface and Ollama to connect with a locally running AI model.

✨ Features

* 💬 Ask questions through text
* 🎤 Voice input
* 🌐 Multilingual support
* 🇬🇧 English
* 🇮🇳 Hindi
* Gujarati
* 🤖 AI-powered answers using Ollama
* 📚 Answers general questions across different topics
* 💻 Help with programming and coding
* 🗑️ Clear chat history
* 🎨 Simple and user-friendly interface

🛠️ Technologies Used

⚙️ Installation and Setup

1. Clone the repository

git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git

2. Navigate to the project folder

cd Multilingual_AI_Voice_Agent

3. Create a virtual environment

python -m venv venv

4. Activate the virtual environment

Windows:

venv\Scripts\activate

5. Install dependencies

pip install -r requirements.txt

6. Install Ollama

Download Ollama from:

https://ollama.com/

7. Download the AI model

ollama pull phi3

8. Run the application

streamlit run app.py

🚀 How to Use

1. Run the application.
2. Select your preferred language.
3. Select or enter the Ollama model name.
4. Type your question or use voice input.
5. Click to interact with the AI assistant.
6. Use Clear Chat to reset the conversation.
